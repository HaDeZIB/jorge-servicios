# Jorge Servicios Integrados · tarjeta digital

Tarjeta de presentación digital de Jorge Moreno (refrigeración, línea blanca y A/C a domicilio en Monterrey): web animada + PDF con links + vCard.

- Editar datos (teléfono, links, mensaje de WhatsApp): `CONFIG` en `build.py`
- Regenerar todo: `python3 build.py` → escribe `docs/` (web, PDF, `contacto.vcf`, QR)
- Logo: `logo.html` (se renderiza a `img/logo.png` con Chrome headless)
- Publicado con GitHub Pages desde `main` / `docs`
